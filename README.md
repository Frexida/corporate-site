# Frexida Website

Frexida のコーポレートサイトです。AstroWind をベースに、Astro + Tailwind CSS + MDX で構築しています。

## Requirements

- Node.js 22.22.3 以上
- npm

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Pages

- `/`
- `/issues`
- `/service`
- `/about`
- `/contact`
