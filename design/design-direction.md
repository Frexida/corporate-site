# Frexida Webデザイン・コンテンツ方針

## 目指す印象

Physical AIに取り組むスタートアップとして、重厚さと先進性を伝える。高級感、男性的、都会的、クラシックで上品、そしてシャープな印象を軸にする。

## ビジュアル

- 背景は暗いチャコールグレーを基本にする。鉄骨や工場の写真を背景に敷かない。
- 配色はベースカラー約70％、アソートカラー約25％、アクセントカラー約5％を目安にする。
- ベースカラー（約70％）：背景のチャコールグレー。ページ全体の基調にする。
- アソートカラー（約25％）：オフホワイトから明るいグレー。文字や動画領域など、ベースを支える色にする。
- アクセントカラー（約5％）：青藍色。短い線や小さな強調に限って使う。オレンジは使わない。
- 重工らしさは、素材写真や装飾で直接表すのではなく、余白、整った区切り、直線的で精密な配置から表現する。
- 装飾は必要最小限にし、情報を詰め込まない。

## 文字

- ヒーロー見出しは「知能を、現実の動きへ。」。日本語の明朝体で、クラシックな品とシャープさを出す。
- 左上のFrexidaロゴ文字はSpace Groteskのようなスマートな幾何学サンセリフ体にする。
- 日本語本文や補助情報は、読みやすくシャープなサンセリフ体にする。
- 実装時は画面幅に合わせて見出しサイズを調整する。

### ヒーローと動画

動画は実写素材として見せず、MuJoCoのようなシミュレーション画面をそのまま置く。アームと座標グリッドが分かる程度にし、動画上の情報表示や操作UIは増やさない。見出しを重ねる場合も、映像を隠さない範囲にする。

### 解決策と提供できる価値

#### 見出し

解決策と提供できる価値

#### リード

私たちは、既存の機械に知能を載せ、価値を大きく拡張する。

#### 本文

専用機械を一から作るのではなく、既存設備や汎用アームを活用する。機械・治具の設計からソフトウェア開発、現場へのシステム導入まで一貫して行い、人のように状況を判断する仕組みで現場の課題を解決する。少量多品種の製造現場や、熟練者の目に頼ってきた検査・判断の繰り返し作業に向く。

この仕組みを工場に広げていくことで、現場のデータを取り込み、AIエージェントと接続する土台を作る。効率化からIoT化へ、そして自律的な機械へと繋げていく。

### Mission / Vision / Value

ミッション、ビジョン、バリューは記号やピクトグラムに置き換えず、文章で見せる。定義の説明は短くし、各項目の意味が伝わる順に配置する。

| 項目                  | 定義                     | 決定事項                                             |
| --------------------- | ------------------------ | ---------------------------------------------------- |
| Mission（ミッション） | 何のために存在するか     | 災害被害を最小限に抑える                             |
| Vision（ビジョン）    | 作りたい未来・あるべき姿 | 自律的に動く機械を実用化し、人命と社会インフラを守る |
| Value（バリュー）     | 提供価値・行動指針       | 危険な作業と軽度の判断の繰り返しを機械に代替する     |

考え方の関係は、Missionで災害被害を最小限に抑え、Visionとして自律的に動く機械を実用化し、Valueとして危険・反復作業を機械に代替させる流れで説明する。

### 事業の三つの軸

三つの軸は、会社の活動を支える考え方として掲載する。

| 軸     | 意味                           | このプロジェクトでの表れ   |
| ------ | ------------------------------ | -------------------------- |
| 防災   | 社会課題への貢献               | 災害被害を最小限に抑える   |
| 持続性 | 事業を継続できる収益をつくる   | 製造業支援                 |
| 探究   | 新しい技術・現場・可能性を探る | AIエージェントの実験・実装 |

防災を社会への目的に置き、持続性で活動を続け、探究で新たな方法を試す。三つが互いを支える関係として示す。

### 会社情報

会社情報は必要な基本項目だけを簡潔に掲載する。事業内容は「ソフトウェア開発・機械設計・システム導入」とする。新しい所在地などの情報を推測で追加しない。

## 避ける表現

- 鉄骨、ボルト、工場設備などを大きく見せる背景
- 実写風のロボットや工場写真
- Mission / Vision / Valueを表すアイコン、ピクトグラム、象徴イラスト
- オレンジのアクセント
- 過剰なチャート、数値表示、技術ダッシュボード、都市の風景
- 導入事例、不要な説明文、CTA
